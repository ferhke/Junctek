# Junctek Home Assistant App Repository

Home Assistant app (addon) repository with the Junctek Battery Monitor.

## Add to Home Assistant

1. Settings → Add-ons → Add-on Store
2. ⋮ → Repositories
3. Add: `https://github.com/ferhke/Junctek`
4. Install **Junctek Battery Monitor**

Source based on [Tsjippy/ha-addons/Junctek](https://github.com/Tsjippy/ha-addons/tree/main/Junctek).
